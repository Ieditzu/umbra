# Evoluția proiectului UMBRA

Fișa de înscriere descrie un prototip care analizează umbra unei persoane înainte ca aceasta să intre în câmpul unei camere. Echipa a descris în fișă o scenă goală, o secvență de mers și o vedere de referință; aceste materiale preliminare nu stabilesc performanța generală a metodei.

Versiunile ulterioare au explorat folosirea umbrei pentru avertizare la un colț sau la ieșirea dintr-o parcare. Direcția actuală folosește poziția Soarelui și geometria clădirilor pentru a afișa umbre și a compara trasee pietonale. Lipsa înălțimilor din date a condus la modulul actual de estimare a înălțimii din lungimea umbrei. Legătura dintre etape este folosirea informației din umbre; problemele și metodele evaluate sunt diferite. Istoricul nu stabilește motivele personale ale schimbării direcției.
